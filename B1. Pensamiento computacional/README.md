# B1. Pensamiento computacional

Nivel Medio: 5 horas.

## Pregunta de orientación
¿Cómo podemos aplicar una solución computacional a un problema del mundo real?

## B1.1 Enfoques del pensamiento computacional

### B1.1.1 Elaborar la especificación de un problema

- La especificación de un problema puede incluir un enunciado del problema, restricciones y limitaciones, objetivos y metas, especificaciones de entrada y de salida, y criterios de evaluación

### B1.1.2 Describir los conceptos fundamentales del pensamiento computacional

- Abstracción, diseño algorítmico, descomposición y reconocimiento de patrones

### B1.1.3 Explicar cómo se aplica el pensamiento computacional a los conceptos fundamentales para abordar y resolver problemas en informática

- El pensamiento computacional no implica necesariamente programar; más bien es un conjunto de técnicas para la resolución de problemas
- Algunos ejemplos del mundo real pueden ser el desarrollo de software, el análisis de datos, el aprendizaje automático, el diseño de bases de datos o la seguridad de redes

### B1.1.4 Trazar diagramas de flujo para una serie de algoritmos de programación

- Utilización de símbolos de diagrama de flujo estándar para representar procesos, decisiones y flujos de control
- Símbolos estándar del diagrama de flujo: conector, decisión, línea de flujo, entrada/salida, proceso/operación, inicio/fin
- Diagramas de flujo para el flujo de ejecución, para seguir los cambios en las variables y para determinar la salida
