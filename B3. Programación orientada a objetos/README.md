# B3. Programación orientada a objetos

Nivel Medio: 7 horas.

## Pregunta de orientación
¿Es la programación orientada a objetos (POO) un paradigma adecuado para resolver problemas
complejos?

## B3.1. Fundamentos de la programación orientada a objetos para una sola clase

### B3.1.1 Evaluar los fundamentos de la programación orientada a objetos
- Modelar entidades del mundo real utilizando conceptos de programación orientada a objetos: clases, objetos, herencia, encapsulación, polimorfismo
- Las ventajas y desventajas de utilizar la programación orientada a objetos en diversas situaciones de programación

### B3.1.2 Elaborar un diseño de clases, sus métodos y su comportamiento
- Clases y sus métodos, en función de los requisitos de la aplicación
- Uso de diagramas de clases del lenguaje de modelado unificado (UML) para representar relaciones entre clases, atributos y métodos, con el fin de facilitar el diseño y la planificación eficaces de software

### B3.1.3 Distinguir entre variables y métodos estáticos y no estáticos
- Diferencias entre variables y métodos estáticos y no estáticos, incluyendo su uso y alcance
- Cuándo utilizar variables de instancia en lugar de variables de clase, y cómo aplicar estos conceptos eficazmente en el código

### B3.1.4 Elaborar código de programación para definir clases e instanciar objetos
- Cómo definir clases y crear objetos a partir de esas clases
- Función de los constructores en la inicialización del estado de un objeto y el establecimiento de los valores iniciales de sus atributos para definir su estado o características en el momento de la creación

### B3.1.5 Explicar y aplicar los conceptos de encapsulación y ocultación de información en la programación orientada a objetos
- Principios de encapsulación y ocultación de información
- Aplicar modificadores de acceso como privado y público
- Controlar el acceso a los miembros de la clase
- La importancia de limitar el acceso para mantener la integridad y la seguridad del estado de un objeto
