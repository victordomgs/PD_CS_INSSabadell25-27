## Pregunta de orientación
¿Cómo podemos aplicar la programación informática a la resolución de problemas?

## B2.1 Fundamentos de programación

### B2.1.1. Elaborar y rastrear programas utilizando una serie de variables globales y locales de diversos tipos de datos
- Tipos de datos: valor booleano, carácter, decimal, entero, cadena

### B2.1.2 Elaborar programas que puedan extraer y manipular subcadenas
- Elaboración de programas que identifiquen y extraigan con precisión subcadenas de cadenas dadas, demostrando la capacidad de realizar diversas manipulaciones, como alterar, concatenar o sustituir

### B2.1.3 Describir cómo utilizan los programas las técnicas habituales de manejo de excepciones
- Los puntos potenciales de falla en un programa deben incluir entradas inesperadas, indisponibilidad de recursos y errores lógicos.
- La función del manejo de excepciones en el desarrollo de programas.
- Las construcciones de manejo de excepciones que gestionan eficazmente los errores deben incluir try/catch en Java, y try/except en Python, junto con el bloque finally.

### B2.1.4 Elaborar y utilizar técnicas habituales de depuración
- Las técnicas de depuración pueden incluir tablas de seguimiento, depuración de puntos de ruptura, sentencias de impresión y ejecución de código paso a paso.

## B2.2 Estructuras de datos

### B2.2.1 Comparar las estructuras de datos estáticas y dinámicas
- Diferencias fundamentales entre las estructuras de datos estáticas y dinámicas, incluidos sus mecanismos subyacentes para la asignación y redimensionamiento de la memoria
- Ventajas y desventajas de cada tipo en diversas situaciones, teniendo en cuenta factores como la velocidad, el uso de memoria y la flexibilidad

### B2.2.2 Elaborar programas que apliquen matrices y listas
- Matrices unidimensionales (1D), matrices bidimensionales (2D) y ArrayLists en Java
- Listas unidimensionales (1D) y listas bidimensionales (2D) en Python
- Agregar, eliminar y recorrer elementos en una lista dinámica

### B2.2.3 Explicar el concepto de pila como estructura de datos “último en entrar, primero en salir” (LIFO)
- Debe incluir operaciones fundamentales como push, pop, peek e isEmpty
- Cómo afectan las operaciones de pila tanto al rendimiento como al uso de memoria
- Una pila adecuada para un problema específico

### B2.2.4 Explicar el concepto de cola como estructura de datos “primero en entrar, primero en salir” (FIFO)
- Debe incluir operaciones fundamentales como enqueue (poner en la cola), dequeue (quitar de la cola), front (llevar al frente) e isEmpty
- Cómo afectan las operaciones de cola tanto al rendimiento como al uso de memoria
- Una cola adecuada para un problema específico

## B2.3 Constructos de programación

### B2.3.1 Elaborar programas que implementen la secuencia correcta de instrucciones de código para cumplir los objetivos del programa
- El impacto del orden de las instrucciones en la funcionalidad del programa
- Formas de evitar errores, como bucles infinitos, interbloqueos (deadlocks), salidas incorrectas

### B2.3.2 Elaborar programas utilizando estructuras de selección adecuadas
- Debe incluir if, else, else if (Java) y elif (Python) para ejecutar diferentes bloques de código basados en condiciones especificadas
- Estructuras de selección con o sin operadores booleanos (AND, OR, NOT) u operadores relacionales (<,<=, >, >=, ==, !=) para controlar eficazmente el flujo del programa

### B2.3.3 Elaborar programas que utilicen estructuras de bucle para realizar acciones repetidas
- Tipos de bucles, incluidos los bucles contados y condicionales, y uso adecuado de cada tipo
- Declaraciones condicionales dentro de bucles, utilizando operadores booleanos o relacionales para controlar la ejecución del bucle

### B2.3.4 Elaborar funciones y modularización
- Funciones para definir bloques de código reutilizables con diferentes entradas
- Modularización para crear código bien estructurado, reutilizable y mantenible
- Principios de alcance (local frente a global)
- Los beneficios de la modularización del código, aplicando este concepto a diversas situaciones de programación

## B2.4 Algoritmos de programación

### B2.4.1 Describir la eficiencia de algoritmos específicos calculando su notación Big O para analizar su escalabilidad
- Las complejidades temporales y espaciales de los algoritmos y el cálculo de la notación Big O
- Elección del algoritmo en función de los requisitos de escalabilidad y eficiencia

### B2.4.2 Elaborar y rastrear algoritmos para implementar una búsqueda lineal y una búsqueda binaria para la recuperación de datos
- Diferencias de eficiencia entre los distintos métodos de búsqueda lineal y binaria
- Uso de la técnica de búsqueda en función de los requisitos de eficiencia: por ejemplo, buscar en una base de datos una lista ordenada/indizada de nombres para encontrar un número de teléfono, frente a buscar por el número para identificar el nombre

### B2.4.3 Elaborar y rastrear algoritmos para implementar la ordenación por burbujas y la ordenación por selección, evaluando sus complejidades temporales y espaciales
- Complejidades de tiempo y espacio de cada algoritmo, denotadas por sus respectivas notaciones Big O
- Ventajas y desventajas de cada algoritmo en términos de eficiencia en varios conjuntos de datos

## B2.5 Procesamiento de archivos

### B2.5.1 Elaborar código para realizar operaciones de procesamiento de archivos
- Programas que manipulan archivos de texto.
- Abrir un archivo secuencial en varios modos (lectura, escritura, anexión).
- Cómo leer de archivos y escribir en archivos, añadir datos a archivos existentes y cerrar archivos una vez finalizadas las operaciones.
- Las clases para usuarios de Java pueden incluir Scanner, FileWriter y BufferedReader.
- Las funciones para los usuarios de Python pueden incluir open(), read(), readline(), write(), y close().
